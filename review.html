專題定位

本作品以「AI 聊天 + 遊戲互動 + 管理功能」為主軸，讓使用者在 Discord 平台上就能直接體驗一個完整、可運行的智慧機器人服務。

為什麼這個作品值得被看見

  • 支援本地 AI，降低 API 成本並保有隱私友善特性
  • 整合多種功能模組，呈現完整產品概念而非單一功能 demo
  • 具備可擴充性與維護性，適合做為專題與未來升級的基礎

評審重點

在展示時可以從 功能完整度、技術整合度、實用價值 三個角度說明作品的亮點，讓評審能快速掌握專題核心。

核心功能總覽

  • 🤖 AI 對話：支援 Ollama 本地模型，提供連續對話與角色切換
  • 🎮 經濟與遊戲：金幣、釣魚、挖礦、寵物與排行榜系統
  • 🛠️ 管理與維運：統計、備份、日誌、權限管理
  • 🌐 部署能力：可搭配 Docker 與 ngrok 進行遠端展示與測試

作品亮點與價值

低成本 AI

透過 Ollama 本地部署模型，減少雲端 API 成本，同時提供更穩定且可控的實驗環境。

高整合度

AI 對話、資料儲存、遊戲邏輯、管理功能全部整合在同一個系統中，形成完整產品感。

易於延伸

未來可加入排行榜、任務系統、語音互動、圖像生成等擴充功能，提升作品深度與可展示性。

技術架構

層級 技術 用途
互動入口 Discord / Discord.py 提供使用者指令、對話與社群互動介面
AI 引擎 Ollama + Qwen2.5-1.5B-Instruct 本地生成回答、角色設定與連續對話支援
資料層 JSON / user_data.json 儲存使用者資料、偏好設定與互動記錄
部署與展示 Docker / ngrok 支援遠端啟動、雲端測試與簡報展示

常用指令

  • !ask 問題：提問 AI
  • !mode [角色]：切換角色
  • !lan [語言]：切換回應語言
  • !help / !guide：說明與操作提示
  • !admin stats：管理員查看統計
